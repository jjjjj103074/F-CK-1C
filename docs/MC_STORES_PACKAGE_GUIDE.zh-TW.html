本包包含同一份來源建置的新版 DLL、Lua 與掛載記錄功能。Windows 建置及自動驗證已通過，DCS 實測由本輪完成。

安裝

  1. 關閉 DCS；將原本的 Saved Games\DCS\Mods\aircraft\F-CK-1C 移到其他地方備份。
  2. 解壓 ZIP，把裡面的整個 F-CK-1C 放入 Saved Games\DCS\Mods\aircraft\。使用 DCS.openbeta 時，改放到該目錄。
  3. 確認模組內有 bin/F-CK-1C_EFM.dll。開啟 DCS，建立 F-CK-1C 地面熱機任務，無限彈藥關閉。

要測試什麼

你可以自行安排任務和掛載，依進入任務的順序回報配置。各配置穩定後保持 5 秒；不必發射導彈。

必要項目 怎麼測 正常結果
全空 九掛點全空，進任務後保持 5 秒 MC 九站無掛載、數量 0，飛彈總數 0
混合掛載 分別放入可選的飛彈、炸彈／多聯掛架、副油箱、莢艙，保持 5 秒 每一站型號及數量與任務掛載一致；非飛彈也有各站資料
涵蓋九站 用多個任務或地勤換掛，讓每一個掛點至少出現一次有掛載 每一站的位置對應正確；MM 與 MF／MB 用不同配置測
地勤換掛 按 反斜線 \ → F8（地勤）→ F1（重新裝填與加油），更換型號、清空部分站位並補滿機砲；地勤完成後保持 5 秒 MC 跟隨新掛載，清空站位不留舊型號，重新掛彈版本前進
機砲彈量 機鼻朝空曠處。按 右 Ctrl＋D 進入 DGFT；按住 Space 約 1 秒後放開，保持 5 秒；按 1 回 NAV、按 右 Shift＋M 關閉主保險 觀察槍口火光／射擊聲；原生彈量若有效，應隨射擊下降、停射後保持。估算與原生來源由日誌判定

多聯掛架請回報實際掛幾枚；記錄將用來確認 DCS 的 count 是武器數量還是掛架組數。 機砲只需回報「出彈／未出彈」，無須數彈數。

測完回傳

按 Esc 結束最後任務後，先收集檔案，再重新啟動 DCS。

  1. 模組內 log/debug.csv，涵蓋整輪測試。
  2. Saved Games/DCS/Logs/dcs.log（或 DCS.openbeta 對應目錄）。這份含 DCS 原始掛載欄位與彈量 API 的實際結果，供核對 CSV。
  3. 任務執行順序與每一站的掛載；有地勤換掛時，列出換掛前後。可附 .miz，或直接貼下表。
