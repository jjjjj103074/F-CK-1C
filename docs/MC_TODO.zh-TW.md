# MC 待討論事項

## 飛彈解籠與發射資格

- [ ] 定義解籠的武器適用範圍、尋標器狀態來源及按下／放開行為。
- [ ] 檢視現有「空對空發射須按住解籠」與機砲資格的關係。
- [ ] 定義 Targeting、FC、SM 與原生武器介面的分工。

## CMS 反制操作與程序

- [ ] 依飛機參考資料討論 CMS 前／後／左／右的操作意圖與程序選擇。
- [ ] 將彈種、數量及間隔整理成反制程序設定。
- [ ] 討論手動／半自動／自動、同意施放與中止的規則。
- [ ] 整合已驗證的 C++ 庫存與施放介面，規劃反制 System 的執行責任。
- [ ] 決定 CMS Press 的需求與對應設備。

## TMS 與感測器操作

- [ ] 依本機已實作的雷達與感測器能力，定義 SOI、TMS 四向及短／長按映射。
- [ ] 規劃獨立的雷達游標／天線操作入口。

操作鍵與參考資料見 [MC 操作說明](MC_CONTROLS.zh-TW.md)。
