# 原生機砲正式整合規格

依據 2026-11-08 實機結果與使用者要求：以已驗證 C++ 來源供應 MC／SM，移除多餘 Lua，遵循專案規範並整理 DCS API 指引。

1. 原生呼叫由 DcsBridge 私有 GunAmmunition 目錄持有；Core／SM 維持型別化觀測。
2. 每次飛行核對已載入 module 的 x64 PE、timestamp、image size、局部程式指紋及必要匯出符號，使用本專案實測成功的配置。
3. 預設啟用正式來源，每 0.1 秒取樣；MC 維持 32 Hz。
4. 有效零發與來源無效分別表示；資料使用來源 revision，SM 保留既有過期與最近有效值語意。
5. 等待 module／payload／mount 建立時持續取樣；原生呼叫失敗則停止該飛行呼叫，重開任務重新建立。
6. 保留記憶體可讀性、函式可執行性檢查與 SEH，並處理讀取例外。來源狀態變化與版本核對使用既有 EventLog，數字沿用既有 debug.csv。
7. 移除 Export 彈量程式、CMS 彈量接收／編碼／逾時、對應自訂命令與參數、AmmoProbe runtime 及舊測試包產生工具；保留掛點、CMS 操作與 HMCS 呈現。
8. ID／參數生成檔透過專案產生器更新。正常安裝與套件包含舊 Export 區塊移除器，先備份並保留其他匯出器內容。
9. DCS API 指引記錄執行環境、讀取契約、版本配置、有效性／頻率／生命週期、實機證據與更新流程，並由既有指南連結。
10. 測試涵蓋原生版本拒絕、物件鏈／數量限制、來源節流／零值／重設／失敗鎖定、MC 傳遞、Lua 既有操作及舊入口清理。完成排版與完整 Windows 建置／分析／原生驗證。

原生互通證據及實機紀錄見 [DCS API 指引](DCS_API_GUIDE.zh-TW.md)。
正式版仍待 DCS 補測：零發、地面補彈、換任務；驗證報告區分離線測試與實機證據。
